# @genui/ui-compiler

See [architecture](https://github.com/Pushparajan/genui/blob/main/docs/rag/architecture.md) and [development guide](https://github.com/Pushparajan/genui/blob/main/docs/rag/development.md) for contracts, model adapters, permissions, and fixture/production boundaries.
